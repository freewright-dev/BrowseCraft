# Engine compatibility matrix

Generated by `BLESS=1 cargo test compat` from the fixtures in `compat/`; do not edit by hand.
It covers BrowseCraft's own engine only (the parser, cascade, layout and
painter that draw internal pages), never a page shown by WebView2 or Servo.

- **pass**: the engine matches every expectation (checked by `cargo test`).
- **known-fail**: the engine differs from the specification; `cargo test` fails
  when it starts to match, so this list stays honest.
- **unsupported**: the feature is not implemented; the page is never run, so it
  cannot count as a pass.

Each fixture paints fixed-size boxes without text and the engine's box
rectangles are compared to within half a pixel at an 800x600 viewport and
scale 1.0, so fonts, anti-aliasing and the platform do not affect the result.
The fixtures are written for this project; no upstream test files are
copied, so no third-party licence applies and there is no revision to pin.
